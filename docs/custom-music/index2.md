# Custom Music (With Unreal Engine)

## Prerequisites

 - Wwise 2021.1.13.8036
 - A program that can pack UE4 PAK files (repak, UnrealPak)
 - Unreal Engine 4.27 for Cooking Files
 
:::tip
A Wwise License is not needed initially but required if utilizing more than 200 media assets for your Wwise project. You can request one via the Audiokinetic site.
:::

 
 ### Setting Up Wwise
 When opening up your Wwise Project, there will be a couple settings for you to consider viewing and changing first.
